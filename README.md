# ancient-coins
Our project utilizes deep learning to analyze and classify ancient coins.
We train and test an instance of the `timm` 21k ImageNet, a PyTorch computer vision model.

The Corpus Nummorum Greco-Roman coins on which our model is trained and tested can be found at [Zenodo](https://zenodo.org/records/10033993).
Other coin datasets are scraped by coins_explore_prep_train.ipynb from the following American Numismatics Society collections:
* [PELLA](https://numismatics.org/pella/) (Argead Dynasty Macedonia)
* [BIGR](https://numismatics.org/bigr/) (Indo-Greek Bactria)
* [SCO](https://numismatics.org/sco/) (Seleucid Dynasty Persia)
